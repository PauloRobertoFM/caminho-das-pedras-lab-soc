# Etapa 3 — Virtualização com Proxmox

> Metáfora: um prédio com vários apartamentos

## Objetivo
Rodar vários servidores do lab em um único equipamento.

## O que você vai montar
Containers e máquinas virtuais, cada um com uma função.

## Ordem recomendada
Instalar o Proxmox, criar o primeiro container e só depois os demais.

## Erro comum
Criar mais máquinas do que o armazenamento aguenta (overcommit do disco).

## Checklist de conclusão
- [ ] Primeiro container criado
- [ ] Espaço em disco monitorado
